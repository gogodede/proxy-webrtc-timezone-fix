- name и description манифеста переведены на строки __MSG_; extensionDescription
  во всех локалях заменено унаследованным текстом FoxyProxy на описание форка.
- Страница приватности и секция WebRTC/часового пояса в popup переведены на

  жёстко заданы по-русски.
- Добавлены недостающие строки команд и documentURL в локали de, es, fa, fr,
  ja, pl, pt_BR, ru, uk, zh_CN, zh_TW.
- Changelog на странице About подписан как апстримный, добавлена ссылка на
  CHANGELOG.md форка.

Опубликовано: GitHub Release v1.1.1 с ZIP-ассетом расширения.

## 1.1.0 — 2026-11-17

Публичный релиз под именем Proxy WebRTC Timezone fix.

- Переименование во всех локалях, манифесте и интерфейсе; новые иконки.
- Автор манифеста и экран About: gogodede; атрибуция источников в NOTICE.md.
- Удалены донатные и коммерческие ссылки апстрима (Stripe, PayPal,
  getfoxyproxy.org/order, support.getfoxyproxy.org) и Google-Translate
  форма в справке, ведшая на сайт оригинала.
- Удалён импорт платного FoxyProxy-аккаунта (import-account.js,
  вызов get-accounts.php).
- Сервисы getfoxyproxy.org заменены: определение IP и геолокация прокси —
  на ip-api.com, кнопка проверки IP — на ipleak.net, строка
  getfoxyproxy.org убрана из списка сервисов проверки IP.
- Таблица extension ID в справке заменена на generic-плейсхолдер.
- Репозиторий: только extension/ и документы; архивы и распакованные
  исходники апстрима не публикуются.
- Лицензия: GPL-2.0 (по лицензии исходного FoxyProxy 8+).

## 1.0.0 — 2026-11-17

- Подготовлена локальная сборка FoxyProxy 9.7, WebRTC Control 0.3.5 и
  Change Timezone 3.0.0 с одним Manifest V3 и одним фоновым процессом.
- Добавлены независимые переключатели WebRTC и времени в popup FoxyProxy,
  общая страница приватности и отдельное пространство хранения настроек.
- Сохранены исходные возможности настройки прокси и импорта FoxyProxy.
- Адаптированы исходные WebRTC-блокировки и подмена Date для MAIN world.
- Исправлены некорректное GMT в текстовой дате, вызов Date без new,
  принудительная перезапись явно указанной зоны Intl и общий сброс хранилища.
- Расчёт текущего UTC-смещения использует базу Chrome вместо старой Moment.
- Подготовлены инструкция установки и ZIP для распаковки.
- Известные ограничения: асинхронное применение настроек на странице;
  подмена времени не охватывает workers и полную историческую семантику Date.
  После изменений требуется перезагрузка вкладок. Настройки и подключения
  старых расширений автоматически не перенесены.

Проверено в отдельном Chromium (Chrome for Testing) через Playwright:
- Загрузка Manifest V3, popup и обоих экранов настроек — успешно.
- Сохранение через интерфейс, политика WebRTC и блокировка объектов — успешно.
- Asia/Katmandu: UTC+05:45, Date(), Date.toString и сохранение явно заданной UTC — успешно.
- Фрейм другого origin и страница со строгой CSP — успешно.
- Выбор HTTP-прокси в popup и реальное прохождение HTTP-запроса через локальный сервер — успешно.
- Сброс времени сохраняет прокси и WebRTC; отключение и перезагрузка возвращают WebRTC — успешно.
- Синтаксис 51 JavaScript-файла и точки входа manifest — успешно. Ошибок страниц в проверке нет.

HTTPS CONNECT, авторизация на реальном внешнем прокси и все унаследованные
функции FoxyProxy отдельно не проверялись. Публикация и установка в личный
профиль Chrome не выполнялись.
